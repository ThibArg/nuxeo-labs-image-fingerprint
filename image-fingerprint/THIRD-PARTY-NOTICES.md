## Using the image

Building the image and running it inside your organization, including as an HTTP service called by
Nuxeo, creates no copyleft obligation. **Every Python and ML component above is permissive**
(MIT / BSD / Apache-2.0 / PSF), and none of them is GPL, LGPL or AGPL. `tqdm` is MPL-2.0, which is
file-level copyleft and is not triggered by merely using the library.

This is the practical difference with the sibling `nuxeo-labs-ifc-converter` project, whose image
contains LGPL components (IfcOpenShell, Open CASCADE) and therefore cannot be redistributed without
a source offer.

## If you distribute the built image

The Python layer imposes only attribution: keep the license texts that ship in each
`*.dist-info/` directory, and the MIT notice for TrustMark and its weights.

The **Debian base image** is the part that carries real obligations, as it does for any
Debian-derived image: it contains GPL-licensed system tools. If you push this image somewhere people
outside your organization can pull it, you become a distributor of those packages and must include
their notices (`/usr/share/doc/*/copyright`) and be able to provide or offer the corresponding
Debian source packages.

That obligation is ordinary and well understood - it is the same for every `python:*-slim` image in
existence - but it is the reason the simplest path remains: share this repository and let each
organization build its own image.

This document is a summary, not legal advice.
